# AENS Escrow

Trustless Domain Trading on æternity.

AENS Escrow is an open-source smart contract system for decentralized domain trading on the æternity blockchain.

Buyers can purchase AENS domains directly through smart contracts using AE. Domain ownership is transferred atomically upon successful payment, while sellers retain the ability to reclaim their domains after an expired listing.

## Core Features

- Trustless domain trading
- Native AE payments
- Atomic payment and domain transfer
- Time-based seller reclaim
- Publicly verifiable Sophia source code
- Reproducible smart contract compilation
- Superhero Wallet integration

## Vision

Build open, permissionless, and verifiable trading infrastructure for the æternity Name System.
